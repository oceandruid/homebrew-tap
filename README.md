# Oceandruid Tap

## How do I install these formulae?

`brew install oceandruid/tap/<formula>`

Or `brew tap oceandruid/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "oceandruid/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
